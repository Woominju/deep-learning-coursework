# Deep-learning

Deep-learning coursework from Fall 2023, written in Google Colab with TensorFlow/Keras.
Each notebook opens directly in Colab from its badge.

| Notebook | Topic | Data |
|---|---|---|
| `11_19_assignments_of_heart_rate.ipynb` | Fully-connected ANN for binary classification | Heart disease (UCI) |
| `11_26_kfold_reservation.ipynb` | ANN with stratified k-fold cross-validation | Hotel reservations (Kaggle) |
| `smiling_face_non_smiling_face.ipynb` | CNN image classifier (smiling vs. non-smiling) | Face images (Google Drive) |
| `GAN_non_smile_2nd_version.ipynb` | GAN (generator + discriminator) on face images in LAB color space | Face images (Google Drive) |
| `전이학습.ipynb` | Transfer learning with a pretrained ResNet | CIFAR-10 |
| `hugging_face.ipynb` | Sentiment analysis with Hugging Face `pipeline` | Short text samples |
| `11_25_set_theory_assignment.ipynb` | pandas DataFrame practice | Toy data |

## Stack
Python · TensorFlow / Keras · scikit-learn · pandas · scikit-image · Hugging Face Transformers

## Notes
- The face-image notebooks read data from Google Drive, so the image files are not included here.
- These are course exercises, kept as a record of how I learned the basics.
